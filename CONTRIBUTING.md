# How to Contribute

## Prerequisites

- Have [`git`](https://git-scm.com/) installed.
- Have [`node`](https://nodejs.org/) & [`pnpm`](https://pnpm.io/) installed.

## Installing dependencies

```sh
pnpm install
```

## CI/CD

#### Testing

In each package, you can run tests using:

```sh
pnpm test
```

#### Linting

```sh
pnpm lint
```

#### Formatting

```sh
pnpm format
```
